# AI 基础

## 什么是人工智能？

人工智能（AI）是计算机科学领域，致力于创建能够执行通常需要人类智能的任务的系统——如识别模式、理解语言、做出决策和从经验中学习。

AI 是一个涵盖许多子领域的广泛领域：

- **[机器学习](/docs/fundamentals/machine-learning)** — 无需显式编程即可从数据中学习的系统
- **[深度学习](/docs/fundamentals/deep-learning)** — 使用多层神经网络的机器学习
- **[NLP（自然语言处理）](/docs/nlp)** — 用于理解和生成文本的 AI
- **[计算机视觉](/docs/cv)** — 用于理解图像和视频的 AI
- **[AI 代理](/docs/agents)** — 采取行动以实现目标的 AI 系统

## 从哪里开始

如果你是 AI 新手，以下是建议的学习路径：

1. **[机器学习](/docs/fundamentals/machine-learning)** — 理解基本概念：监督与无监督、训练与推理、过拟合
2. **[深度学习](/docs/fundamentals/deep-learning)** — 神经网络如何从数据中学习表示
3. **[神经网络](/docs/neural-networks)** — 构建模块：层、权重、反向传播
4. **[Transformers](/docs/transformers)** — 现代 LLM 背后的架构
5. **[LLMs](/docs/llms)** — 大型语言模型及其使用方式
