# Glosario

Una referencia rápida de términos clave utilizados en AI Summary Hub.

| Término | Definición |
|---------|------------|
| **RAG** | Generación aumentada por recuperación — combina recuperación con generación mediante LLM. |
| **LLM** | Modelo de lenguaje de gran escala. |
| **Transformer** | Arquitectura basada en auto-atención (p. ej. BERT, GPT). |
| **Agent** | Sistema que percibe y actúa hacia objetivos. |
| **Subagent** | Agente dentro de un sistema de agentes jerárquico. |
| **RDD** | Recuperación-Decisión-Diseño — patrón de razonamiento guiado por especificaciones. |
| **CoT** | Chain-of-thought — razonamiento paso a paso. |
| **ReAct** | Razonamiento + actuación en pasos intercalados. |

_Se añadirán más términos a medida que se amplíen los temas. Consulte los documentos individuales de cada tema para obtener definiciones detalladas._
