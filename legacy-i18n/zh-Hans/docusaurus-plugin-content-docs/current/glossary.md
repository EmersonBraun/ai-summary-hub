# 术语表

AI Summary Hub 中使用的关键术语快速参考。

| 术语 | 定义 |
|------|------|
| **RAG** | 检索增强生成 — 将检索与 LLM 生成相结合。 |
| **LLM** | 大型语言模型。 |
| **Transformer** | 基于自注意力机制的架构（如 BERT、GPT）。 |
| **Agent** | 感知环境并朝目标采取行动的系统。 |
| **Subagent** | 层级智能体系统中的子智能体。 |
| **RDD** | 检索-决策-设计 — 规范驱动的推理模式。 |
| **CoT** | 思维链 — 逐步推理。 |
| **ReAct** | 推理 + 行动交替执行。 |

_随着主题的扩展，将添加更多术语。有关详细定义，请参阅各主题文档。_
